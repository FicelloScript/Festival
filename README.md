# Festival 026a – Site vitrine

Site vitrine d'un festival fictif, réalisé en HTML/CSS dans le cadre du TP de groupe du module IDE et Versioning GitHub (Institut Européen F2i).

L'objectif principal est de travailler en équipe avec Git et GitHub en suivant le GitHub Flow : issues, branches, Pull Requests et revues de code.

## Lancer le projet

1. Cloner le dépôt :
```bash
   git clone git@github.com:FicelloScript/Festival.git
   cd Festival
```
2. Ouvrir `index.html` dans un navigateur, ou utiliser l'extension **Live Server** de VS Code (clic droit sur `index.html` → *Open with Live Server*).

Aucune installation supplémentaire n'est nécessaire.

## Structure

- `index.html` : page d'accueil
- `activites.html` : programmation du festival
- `a-propos.html` : histoire et valeurs du festival
- `contact.html` : formulaire et informations pratiques
- `style.css` : feuille de style commune
